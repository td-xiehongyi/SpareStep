## 操作定义

- 点击任意事项块的九点按钮，打开仅针对该事项的快捷菜单。
- 完成并归档：与正文长按完成的结果一致；直接从首页移入归档。
- 移动到分类：原型默认补充入口，选择已有分类后移动事项；是跨分类拖动的替代入口，可在评审时调整。
- 删除：与左滑后点击删除的结果一致，移入回收站，不永久删除。
- 点击菜单外部或再次点击同一九点按钮关闭；点击另一事项的九点按钮切换目标，不叠加多个菜单。
- 按住九点并移动用于拖动排序；已经开始拖动时不打开菜单，拖动结束也不补触发点击。
- 九点区域不触发正文长按完成；原位文字编辑时仍维持文字操作语义。
- 分类标题的九点柄不在本次新增事项菜单范围内。
