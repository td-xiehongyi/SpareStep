# FTM 黑白 HTML 交互原型

本机预览：http://127.0.0.1:4175/ 。由产品角色独立制作的前端演示，非正式产品服务。
默认 iPhone 屏幕为 393×852 CSS px，外壳、状态栏和安全区保留。浏览器窄窗会整体缩放手机。

主要入口：
- 分类旁 +：末尾插入空块直接输入。正文点击编辑，Enter 换行。
- 新空块输入 `# 分类名` 后 Enter 创建分类。已有正文不会自动转成分类。
- 九点点击：完成并归档、移动到分类、删除；九点拖动：事项排序/跨分类，分类柄排序。
- 浏览正文按住 0.8 秒完成；提前松手取消。编辑时支持文字操作。
- 左滑露出删除，再点击进入回收站。
- 设置 → 归档与回收站 → 恢复为待办。

演示状态只在当前页面内存中，刷新即恢复初始示例。模拟键盘显示用于布局演示，电脑用实体键盘输入。不要用于保存真实事项。

源码：src/Prototype.tsx、src/prototype.css。
验证：design-qa-report.md；构建 `npm run build` 已通过。
预览如被关闭，可在此目录运行 `npm run dev -- --host 127.0.0.1 --port 4175 --strictPort`。
